# 2026-11-10 系统推进记录

## 本轮完成

1. 新用户可从登录页注册，进入首次测评，保存个人资料、完整量表分数和基线，自动生成初始模板处方。未完成测评不能开始训练；重复提交首次测评会提示使用后续测评。
2. 后端启动时执行现有轻量迁移，补齐旧 SQLite 库的隐私同意、首次测评状态与报告字段；正式启用首次测评和知识库接口。
3. 结束训练统一保存报告和知识库，二者一起成功或一起回滚。同一会话重复结束或并发结束只保存一份报告和归档，失败后可重试。
4. 新增「训练历史与知识库」，可查看完成次数、归档数量、有效模型均分及每次训练报告。报告链接携带训练编号，刷新仍可打开。
5. 演示 / 备用结果明确显示暂无有效评分，不进入均分、错误汇总或成绩对比，不写入假体测、不调整处方。训练结束后，真实模型结果也保留待审核。
6. 报告和知识库保留姿态来源、帧数及预留动作计数结果；没有算法结果时显示暂无，不使用假次数。
7. 未完成训练支持恢复和取消。开始训练时保存已有姿态与视频引用，训练中重新解析视频后保存新输入；刷新页面或从历史页继续，沿用原训练编号。取消不生成报告或归档，也不增加完成次数。
8. 训练历史按每页 10 条展示，可按状态、动作筛选。超过最近 20 条统计窗口的旧记录，仍能显示自身评估摘要；顶部均分仍说明为最近归档窗口统计。
9. 小窗口下导航可展开、收起，避免遮住训练及历史内容。

## 如何验收

先按 README 启动前后端，AI 服务可不启动。

1. 登录页切换注册，设置一个新账号，勾选同意并提交。
2. 自动进入「首次测评」。尝试进入「运动中监测」，应回到首次测评。
3. 填写资料及所有量表项目换算分（测试可统一填 70），勾选同意并保存。应打开初始模板处方 v1。
4. 回总览，点击「一键跑通演示闭环」。应出现训练报告，评估状态为演示 / 备用结果、模型评分为空。
5. 打开「训练历史与知识库」。应有一条完成记录、一条归档，模型均分显示暂无；点击本次报告并刷新，仍能看到该报告。
6. 打开当前处方，版本仍为 v1。再跑一次演示，应增加一条训练记录，处方仍为 v1。
7. 去「运动中监测」，选择并解析离线视频后开始会话，记下训练编号；刷新页面，应恢复相同编号。也可离开页面，在历史页筛选「未完成」，点「继续本次训练」。结束后应生成该编号的报告，并保留已保存的姿态摘要。解析新视频需要相应姿态服务可用；未运行真实模型时，此步骤只能验收恢复和归档流程，不能验收算法效果。
8. 另开一次训练并点「取消本次训练」。历史应标为「已取消」，没有报告入口，完成及归档数量不增加；可以再开始新的训练。
9. 历史记录超过 10 条后点「下一页」，再分别筛选状态、动作；筛选后从第 1 页开始。缩窄窗口后点「展开导航」「收起导航」，页面内容应能正常阅读和操作。

恢复范围：保存的姿态数据和视频引用可恢复；浏览器里的本地文件预览需重新选择，摄像头需重新打开。未结束时的摄像头实时帧暂未持续保存，刷新会丢失这部分尚未提交的帧。

## 本轮验证

- 后端自动检查：15 项通过，覆盖首次测评校验、旧库迁移、并发 / 重试归档、失败回滚、0 分统计、排除演示成绩、演示处方不重复创建，以及恢复保存输入、取消幂等、归属参数校验、分页与筛选、窗口外旧记录摘要。
- 前端生产构建通过。
- 临时数据库下的 API 冒烟通过；浏览器实际完成注册、首次测评、演示报告、历史回看、刷新和处方版本检查。继续推进时，使用临时库及姿态测试数据完成未完成训练恢复、刷新后结束、取消、历史筛选与翻页，并验证窄屏导航展开和收起；未改动项目现有数据库。
- 以上验证不代表 RTMPose、动作计数或真实 Video CoT 算法效果已验收；本轮未运行真实模型评估。

## 下一轮可继续做的系统工作

1. 正式账号与权限：替换开发登录，由后端验证登录身份和每条数据的归属；完成后才适合部署多人使用。当前传入 `user_id` 的一致性检查不等于身份鉴权。
2. 处方审核流程：先设计明确的人工审核操作和记录，再接训练建议；当前处方由模板生成，不根据演示成绩调整。
3. 知识库详情：展示更多姿态与提示摘要，给用户查看单条归档的明确入口。
4. 摄像头训练保存：设计分段保存与恢复，防止刷新丢失尚未提交的实时帧。

算法工作不作为以上系统工作的前置条件。量表换算规则、医疗决策及复杂模型仍需单独确认和验证。
