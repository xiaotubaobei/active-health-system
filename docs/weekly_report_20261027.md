## 三、这周我重点做的（在框架上往前推）

**1. 数据**

演示视频我整理进了运动页下拉列表（`demo_videos`），方便您看、我也方便反复测。

**2. 系统**  
在「运动中监测」里加了离线视频模式：选演示样本 → 解析姿态 → 「开始会话」登记这次训练 → 「结束并生成报告」。运动中到报告这条，不接摄像头也能跑通。
