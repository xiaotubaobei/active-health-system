# 2026-11-11 系统推进记录

## 本轮完成：处方人工审核

1. 用户在「运动处方」填写指定审核人的账号，明确同意共享本次处方、个人档案和最近测评快照后提交。
2. 审核人在「处方人工审核」查看申请、展开送审资料，填写意见并选择通过或退回。医师可处理健身与医疗模板，处方师只处理健身模板。
3. 通过后，本版标记为正式处方，保留原有动作、强度和版本号。退回后保留原状态，用户可以补充说明重新提交。
4. 用户可以撤回待审申请；生成新版会自动使旧待审申请失效，防止旧版本继续被批准。重复送审和重复审核不能覆盖已有结果。
5. 双方可以回看已完成记录，包括审核人、时间、意见和当时的资料快照。审核人不能借此访问用户其他训练、视频或个人档案接口。
6. 已注册个人账号由本地维护工具设置审核角色，变更角色后必须重新登录。审核人登录后直接进入审核页面。

详细操作见 [prescription_review.md](prescription_review.md)。
